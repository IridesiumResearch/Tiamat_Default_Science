# Third-party assets

One line per binary asset that is not Iridesium's own: what it is, where it
came from, who made it, under which licence, and where it lives in this
repository. Nothing yet: every texture in `mods/tiamat_default_science/textures/`
is a placeholder drawn by `tools/make_textures.py`, every model one built by
`tools/make_models.py`, and every sound one written by `tools/make_sounds.py`:
Iridesium's own.
